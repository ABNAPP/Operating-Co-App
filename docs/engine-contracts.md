## Intent
Define interfaces and data contracts between input/reference data and planned valuation engine stages.

## Contract Rules
- Contracts are implemented in shared TypeScript modules under the Global Valuation Engine.
- Company-specific results store outputs generated by applying these shared contracts to one company.
- Dashboard consumes outputs but does not execute contracts or valuation logic.

## Display Formatting Contract (UI only)
- Numeric display is standardized in `lib/utils/formatters.ts`; table cells may use `formatTableCell` / `FormattedTableCell`.
- Use `formatNumber` (2 dp), `formatPercent` (rates/margins/growth/tax/WACC/ERP/spreads), `formatAmountMillions` (financial amounts in millions), `formatPerShare`, and `formatFxRate` (FX at 4 dp).
- Formatting must not alter stored/imported raw values or engine math.
- Skip formatting for IDs, tickers, series IDs, dates, statuses, row counts, and labels; use `formatColumnHeader` for amount units (`(m)`, `USDm`, etc.).

## Phase 4C-2B-10 Coverage (Beta Relevering & Selected Beta Policy)
- `computeBetaPolicy(input)` — pure beta policy; `computeBetaPolicyForCompany(company)` — server wrapper.
- Relevered Beta = Unlevered Beta × (1 + (1 − taxRate) × DebtToEquity). Values are decimals, not percent.
- `CompanyBetaPolicyInputs` on company model — optional market/book D/E, tax, override (mock scaffold labelled).
- Missing D/E or tax → Review; industry levered reference may display but not as final WACC beta.
- Manual override → selectedBeta = override, status Review.
- No Cost of Equity, WACC, or valuation engine math.

## Phase 4C-2B-11 Coverage (WACC Engine Foundation)
- `computeWaccForCompany(company)` — assembles inputs from Beta Policy, valuation-currency riskfree, country-of-risk ERP, and explicit `waccFoundationInputs` (mock scaffold).
- Formulas: CoE = Rf + β × ERP; After-tax CoD = Pre-tax CoD × (1 − T); WACC = E-weight × CoE + D-weight × After-tax CoD.
- WACC output is foundation-only — not connected to FCFF, terminal value, intrinsic value, or Dashboard decisions.
- Synthetic rating / ICR cost of debt not implemented; revenue-weighted ERP pending (country-of-risk ERP used with Review note).
- ISM-sector must not be used for WACC.

## Phase 4C-2B-13 Coverage (Reinvestment / FCFF Engine Foundation)
- `computeReinvestmentFcffForCompany(company)` — assembles operating inputs from company historical/forecast scaffold; benchmark config may add cyclical/high review notes only.
- Formulas: NOPAT = EBIT × (1 − T); Direct Reinvestment = CapEx − D&A + ΔNWC; Sales-to-Capital Reinvestment = ΔRevenue / Sales-to-Capital; FCFF = NOPAT − Reinvestment.
- Method selection: prefer Direct; Sales-to-Capital fallback; Stable placeholder only; both available → Direct with comparison note.
- Outputs: NOPAT, selected reinvestment method, reinvestment, FCFF, readiness status, missing inputs, warnings — no terminal, DCF/PV, bridge, or intrinsic math.
- Reinvestment / FCFF output is foundation-only — not connected to Dashboard decisions.
- ISM-sector must not be used for Reinvestment / FCFF logic.

## Phase 4C-2B-14 Coverage (Terminal Value Engine Foundation)
- `computeTerminalValueForCompany(company)` — assembles Terminal Value inputs from Reinvestment / FCFF, WACC foundation outputs, and terminal template scaffold inputs.
- Formulas: Terminal FCFF = Final Forecast FCFF × (1 + Stable Growth Rate); Gordon Terminal Value = Terminal FCFF / (Stable WACC - Stable Growth Rate).
- Guardrails: stable growth >= stable WACC => terminal value returned as null with Review/Missing status; missing terminal inputs => null terminal outputs (no fake terminal math).
- Implemented foundation method: Gordon Growth only.
- Not implemented in this phase: Exit Multiple terminal value, Hybrid terminal value, DCF/PV discounting, Firm-to-Equity Bridge, Intrinsic Value, Dashboard decision logic.
- Terminal Value foundation output is foundation-only — no discounting and no connection to bridge/intrinsic value or Dashboard decisions.
- ISM-sector is display-only and must not drive terminal value logic.

## Phase 4C-2B-15 Coverage (DCF / PV Engine Foundation)
- `computeDcfPvForCompany(company)` — assembles PV inputs from Reinvestment / FCFF (forecast FCFF), Terminal Value (terminal value), and WACC foundation outputs.
- Formulas:
  - Discount Factor = 1 / (1 + WACC) ^ yearNumber
  - PV of Forecast FCFF = Forecast FCFF × Discount Factor
  - PV of Terminal Value = Terminal Value × Discount Factor
  - Value of Operating Assets = Sum PV Forecast FCFF + PV Terminal Value
- Guardrails:
  - If WACC is missing/invalid => PV outputs are null (no fake PV)
  - If forecast FCFF is missing => forecast PV is Missing/Review
  - If terminal value is missing => PV terminal value is Missing/Review
  - If WACC <= 0 or yearNumber <= 0 => Review/Missing and null PV outputs
- Implemented foundation scope: discounting + PV forecast FCFF + PV terminal value + operating assets PV sum
- Not implemented in this phase: Firm-to-Equity Bridge, Equity Value, Intrinsic Value / Share, Dashboard decisions
- ISM-sector must not be used to drive DCF/PV logic.

## Phase 4C-2B-16 Coverage (Firm-to-Equity Bridge Engine Foundation)
- `computeEquityBridgeForCompany(company)` — assembles bridge inputs from DCF/PV (Value of Operating Assets) and explicit `balanceSheetBridgeInputs` scaffold.
- Formulas:
  - Total Additions = Cash & Cash Equivalents + Non-Operating Assets
  - Total Deductions = Total Debt + Preferred Equity + Minority Interest + Other Non-Equity Claims
  - Equity Value = Value of Operating Assets + Total Additions − Total Deductions
- Guardrails:
  - If Value of Operating Assets is missing => Equity Value is null (no fake equity math)
  - If major bridge inputs (cash, total debt) are missing => Review/Missing with null Equity Value
  - Total Debt = Gross Debt + Lease Liabilities (explicit gross debt; not net debt)
  - Optional claims may default to zero only when not explicitly provided, with documented scaffold notes
- Not implemented in this phase: per-share value, Intrinsic Value / Share, MOS, entry price, Dashboard decisions
- ISM-sector must not be used to drive bridge logic.

## Phase 4C-2B-17 Coverage (Intrinsic Value / Share Engine Foundation)
- `computeIntrinsicValueForCompany(company)` — assembles inputs from Firm-to-Equity Bridge (Equity Value) and explicit `intrinsicValueFoundationInputs` scaffold.
- Formulas:
  - Share unit `millions`: Intrinsic Value / Share = Equity Value (m) ÷ Selected Diluted Shares (m)
  - Share unit `absolute`: Intrinsic Value / Share = (Equity Value (m) × 1,000,000) ÷ Selected Diluted Shares (absolute)
- Guardrails:
  - If Equity Value is missing => Intrinsic Value / Share is null (no fake per-share math)
  - If shares are missing or ≤ 0 => null per-share output
  - If share unit is missing or not `millions` | `absolute` => Review/Missing with null output
- Not implemented in this phase: MOS, entry price, buy/sell/hold, upside/downside, Dashboard decisions
- Current share price is display-only when provided; it does not drive decisions in this phase.
- ISM-sector must not be used to drive intrinsic value logic.
