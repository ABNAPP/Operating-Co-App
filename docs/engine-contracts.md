# Engine Contracts (Placeholder)

## Intent
Define interfaces and data contracts between input/reference data and planned valuation engine stages.

## Source of Truth
- Master Specification v1.5 is the active source of truth for benchmark-first industry logic.
- Industry Benchmark Config replaces old visible Sector / Industry Mapping naming in primary user workflows.

## Planned Engine Contract List
1. Forecast & Fade Engine Contract
2. Reinvestment & FCFF Engine Contract
3. Risk/WACC Engine Contract
4. Terminal Value Engine Contract
5. Firm-to-Equity Bridge Engine Contract
6. Per-Share Engine Contract
7. Quality/Review Engine Contract
8. Decision Engine Contract

## Contract Rules
- Contracts are implemented in shared TypeScript modules under the Global Valuation Engine.
- Company-specific results store outputs generated by applying these shared contracts to one company.
- Dashboard consumes outputs but does not execute contracts or valuation logic.
